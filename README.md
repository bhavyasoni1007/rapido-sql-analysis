# rapido-sql-analysis
A hands-on MySQL project analyzing Rapido ride-booking data using SQL. The project includes rides, customers, and drivers datasets, with 200 customer and driver records prepared using Excel and imported into MySQL.

The analysis uses SQL concepts such as JOINs, GROUP BY, ORDER BY, HAVING, aggregate functions, filtering, and subqueries to generate insights from the ride data.

**Tools:** MySQL, MySQL Workbench, Excel, SQL
